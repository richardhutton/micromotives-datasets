Base Set

Our own version of SocSci210, the base layer the model learns from before it is tuned on UK data. Every SocSci210 study, and every new study that is not UK-compatible, has exactly one home here: Base trains stage 1 and is rebuilt by us from the original materials; UK trains stage 2 from our clean build; Eval is SocSci210's 40 held-out studies, never trained on, so accuracy and distortion can be measured; Review waits on a UK decision. Order is the build order within each set: most valuable for simulating behaviour first, then the most different from what is already picked, so the model sees as wide a range of experiments as possible.
