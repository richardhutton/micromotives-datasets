Proof of build quality

Condition spot-check

Thirty conditions drawn at random from the built text corpus, one from each of thirty studies. For each, read what we wrote against the passage from the original questionnaire and decide whether a respondent in this version really saw these words before answering this question. The passage shown is the one that sets this version apart from the others, taken from the file named for this study where there is one. It was found by matching text, so check that it belongs to the right version, not only that the words appear somewhere.
